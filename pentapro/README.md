# PentaPRO

Start at [PROCESS index](process/index.md). The five pillars maintain the project's specification.

| Pillar | Responsibility | Records |
| --- | --- | --- |
| PRODUCT | Users, outcomes, domain, requirements, experience, quality and feature acceptance | [overview](product/overview.md), [domain](product/domain.md), [features](product/features.md), [development data](product/development-data.md), [interactive analysis](product/interactive-strategies.md), [numerical contracts](product/numerical-contracts.md), [series statistics](product/series-statistics.md), [quality](product/quality.md), [experience](product/experience.md) |
| PROJECT | Architecture, contracts, decisions, delivery and security constraints | [architecture](project/architecture.md), [interactive analysis design](project/interactive-strategies.md), [decisions](project/decisions.md), [delivery](project/delivery.md), [security](project/security.md) |
| PRODUCTION | Environments, operation, distribution and evolution | [environments](production/environments.md), [operation and distribution](production/interactive-strategies.md), [operations](production/operations.md), [evolution](production/evolution.md) |
| PROOF | Check plans, traceability and actual evidence | [interactive verification](proof/interactive-strategies.md), [verification](proof/verification.md), [traceability](proof/traceability.md), [validation](proof/validation.md) |
| PROCESS | Shared status, authority, change control and execution | [index](process/index.md), [interactive analysis scope](process/interactive-strategies.md), [change control](process/change-control.md), [execution](process/execution.md) |

PentaPRO maintains the current product requirements and the status index; completed change records and their tasks remain in the native [archive](changes/archive/). The [specification coverage](process/specification-coverage.md) maps the maintained requirements to their canonical owners.
