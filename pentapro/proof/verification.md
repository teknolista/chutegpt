The plugin API was probed against the installed binary rather than assumed: `Plugin.define` plus `ctx.session.hook("context", …)` receives `{sessionID, model, system, messages, options, agent, tools}`, and a real user message is stored as `{id, role: "user", content: [{type: "text", text}], metadata}`. Harness-injected user-role context is distinguished by that `metadata`: the plan-mode reminder has none, the conversation checkpoint carries `keepID`/`recent`, and a real prompt carries `{}` (CLI) or `{displayText}` (TUI). A text guard against `<system-reminder>`, `<context>`, `<environment_context>` and `<conversation-checkpoint>` is the second line of defence.

Observed behavior, each in a separate `opencode run --standalone` execution:

- Single-line, multi-line and attachment prompts were appended verbatim with the RFC 5322 local timestamp and `provider/model (agent)`; `senha: hunter2` and an `sk-` key were replaced by `[REDACTED]` markers.
- A request with an intermediate tool call produced exactly one entry, although the model was called more than once.
- `--continue` on the same project appended the new prompt and, because the deduplication is memory-only, also re-appended the previous one: duplicates after a server restart are accepted in this initial version, and no `AGENTS.log.ids` is created.
- With `AGENTS.log` read-only, the run aborted with `[agents-log] falha ao gravar …: EACCES` and no model answer was produced, so no prompt reached the model unlogged.
- A plan-mode session appended only the real prompt, not the injected reminder.
- A real session in this repository exposed a defect that the isolated runs had not: the conversation checkpoint, which carries `metadata` with `keepID`/`recent`, was being logged as a prompt. The filter was corrected to reject that shape, and the log was restarted; the contaminated file is preserved locally as `AGENTS.log.pre-fix` and is not prompt history to keep.
- A Bun unit check run over a copy of the plugin file covered prompt selection (CLI prompt, TUI prompt, checkpoint, plan reminder with and without `metadata`, assistant, tool and system messages), the RFC 5322 format, the attachment marker and redaction of `senha:`, `Bearer`, `sk-` and `ghp_`; all cases passed.
- The restarted repository log captured the first prompt of a fresh session correctly and created no state file.
