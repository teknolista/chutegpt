## Shared conventions

A snapshot is an ordered, validated, nonempty list of draws with seven distinct integers in 1..31 and a month in 1..12. Counts, ranks, IDs and denominators use checked integers. History for draw t consists strictly of snapshot draws before t; use positions in the validated ordered snapshot, not subtraction of contest identifiers. Show range, eligible draw count, excluded count and units with each result. Percent is 100 times numerator divided by its explicitly stated eligible denominator; no eligible observations means unavailable, never 0%. Empty categories are shown where their bounded range is known. Never count an unknown value as zero. All calculations use unrounded values; use IEEE-754 binary64 (`f64`) for real-valued square roots and statistics, in the order written in the formulas. Display and bin real metrics to two decimal places by rounding the computed binary64 value multiplied by 100 to nearest integer, ties to even, then dividing by 100; the binary64 value rather than an ideal exact real controls the result near a boundary. Compute each chart key once from that rounded integer and display from the same key; preserve the unrounded value for further arithmetic. Percentages display to two decimals using the same rule. Integer histogram bins remain exact. Numerical checks must cover finite values, representable binary tie cases and precision against independently calculated reference values. Cross-platform behavior near floating-point bin boundaries requires actual target checks; do not claim exact real arithmetic or platform identity. A missing or invalid optional prize field is unavailable with count and warning; it does not invalidate otherwise valid draw data. Any terminal chart has exact tabular values alongside the graphic.

For a nonempty vector v of length n, define range=max(v)-min(v), mean=sum(v)/n, mean-of-roots=sum(sqrt(v_i))/n, RMS=sqrt(sum(v_i²)/n), MAD=sum(abs(v_i-mean))/n, population SD=sqrt(sum((v_i-mean)²)/n), CV=100*SD/mean, expressed as a percentage, if mean nonzero, otherwise unavailable. No intermediate rounding. This definition applies to S08 and S09. The source vectors here contain positive numbers, so CV is defined. Display a table by draw and a histogram of each metric, separately labeled; precision is as above.

## Strategy contracts and independent examples

- **S01 parity:** per draw count even numbers in 0..7; odd=7-even. Histogram all 8 categories. A=[1,2,3,10,20,30,31] has 4 even and 3 odd.
- **S02 repeat:** intersection size with immediately preceding draw; exclude the first. For B=[1,4,5,10,12,20,31] after A, intersection={1,10,20,31}, size 4. Categories 0..7.
- **S03 recurrence:** maximum size of intersection with any strictly prior draw, first unavailable; histogram 0..7. For B following only A result=4. Unlike Lothon retrospective code, never use later draws.
- **S04 adjacency:** count consecutive sorted pairs with difference 1, histogram 0..6. A has 3. **S05 longest run:** maximum consecutive links, not number of numbers, or 0; histogram 0..6. A has 2. Each independently executable.
- **S06 sum:** exact per-draw sum; histogram actual integer sums. A=97. **S07 digital root:** repeatedly add digits of S06 until one digit; histogram 1..9. A=7. A and B=83 have roots 7 and 2.
- **S08 number dispersion:** apply seven shared measures to the seven sorted values per draw. A gives range 30, mean 13.86, mean-of-roots 3.26, RMS 18.42, MAD 11.27, SD 12.14, CV 87.57% after rounding.
- **S09 gaps:** for each draw use the six positive differences of adjacent sorted numbers. Histogram pooled raw gaps and report all seven dispersion measures by draw and metric histograms. A gives [1,1,7,10,10,1], range 9, mean 5.00, mean-of-roots 2.00, RMS 6.48, MAD 4.00, SD 4.12, CV 82.46%. Pooled gap denominator is 6 times draws; per-draw measures use draws as denominator.
- **S10 decade groups:** groups [1..10], [11..20], [21..30], [31]. Display each draw’s occupancy vector, aggregate occurrence count for each group and histogram of per-draw maximum group occupancy (0..7); group count denominator 7 times draws. A occupancies [4,1,1,1], maximum 4. This explicitly differs from Chutan decade boundary behavior.
- **S11 columns:** group by decimal last digit 0..9; display each draw’s occupancy vector, aggregate counts and histogram of per-draw maximum occupancy. A counts [3,2,1,1,0,0,0,0,0,0], maximum 3.
- **S12 matrix:** per draw compute maximum group occupancy from S10 and maximum last-digit occupancy from S11; histogram both and their sum, plus per-draw values. A gives row max 4, column max 3, sum 7. Neither is a prediction.
- **S13 cycles:** run two independent nonoverlapping series, thresholds 27 distinct numbers and 31 distinct numbers. Start after the previous closure; add an entire draw at once; close on the first draw reaching or exceeding the threshold, counting that closing draw. Show each completed cycle's first and last contest, duration in draws and distinct count; histogram durations over completed cycles only. Show an unfinished tail separately, including its duration and distinct count, but do not treat it as a completed cycle. If no draws remain after a closure there is no tail. For draws [1..7],[8..14],[15..21],[22..28],[25..31], threshold 27 first closes at draw 4 with 28 unique numbers and duration 4, then has a one-draw tail; threshold 31 closes at draw 5 with duration 5. Closing-draw convention differs from legacy candidate-facing cycle counting.
- **S14 ordinal:** assign combinations their 1-based lexicographic rank among N=C(31,7)=2,629,575 using checked exact combinatorics. Histogram ten rank bands indexed floor(10*(rank-1)/N), 0..9; label intervals by integer rank bounds. Also show per-draw ranks and absolute changes from the immediately preceding rank; first has no change. Histogram ten change bands indexed min(9,floor(10*absolute_change/N)); duplicate results remain independent observations and yield zero change. [1..7] has rank 1 in band 0; [25..31] has rank N in band 9; their consecutive difference N-1 falls in band 9. This avoids the legacy duplicate overwrite and ordinal boundary assumptions.
- **S15 individual numbers:** for each 1..31 show appearance count and current number of draws since latest occurrence; a number never seen is unavailable, not zero. If only A exists, 1 has count 1 and delay 0, while 4 has count 0 and delay unavailable. Present counts as bars and all numbers in a table.
- **S16 month:** for each month 1..12, separately from numbers, show count and current draws since last occurrence; never seen is unavailable. If months are [1,2,1], month 1 has count 2 delay 0, month 2 count 1 delay 1, month 3 count 0 delay unavailable. Present counts as bars and all months in a table.
- **S17 historical frequency/absence:** use owner-approved ranking and S20 reference example in [PRODUCT](interactive-strategies.md#confirmed-ranking-and-dispersion-decisions-s17-s20). In addition, for each draw after the first, for all 31 numbers and separately for each of its seven numbers define legacy periodicity=floor(H/count) for H prior draws and positive prior count; never-seen periodicity is unavailable, not the legacy sentinel 0. Display per-draw distributions and the seven shared dispersion measures for both populations of available periodicities, and the selected-seven count >=4; exclude unavailable from this threshold's eligible-number count and identify exclusions. Prior delay=H-1-index_of_last_occurrence, unavailable for never-seen; report its distribution and the seven shared dispersion measures for both populations and the selected-seven count >=5 when all 31 numbers have appeared in prior history, otherwise mark that draw's threshold result unavailable, matching the legacy coverage gate. For the PRODUCT five-draw example and current [1..7], each selected number has periodicity 5 and delay 4, so threshold counts are 7 and 0. Report each histogram's own eligible draw or number denominator and unavailable counts. For any empty vector, every measure is unavailable; for zero mean, CV is unavailable. Keep zero delays in the distributions and measures, correcting legacy omission. These are distinct from top rankings; no category-zero sentinel conflates missingness with a result.
- **S18 distance:** per-draw maximum minus minimum, histogram integer values. A gives 30. Its value duplicates S08 range but remains separately selectable to preserve legacy scope.
- **S19 mean of roots:** calculate sum(sqrt(number))/7 and round to the nearest integer, exact ties to even; histogram integer values. A gives 3. Python's legacy `round` uses ties to even; this is not a statistical median.
- **S20 frequency-delay dispersion:** use the seven current numbers' strictly prior counts and delays, population SD for each vector, then square root of the product and round to integer nearest ties to even; first exclude draws until all 31 appeared in prior history. Histogram and unavailable count. PRODUCT's reference vector yields 0. This corrects the legacy future-data leakage and sentinel frequency offset.
- **S21 weekday prizes:** for each of the seven weekdays show total draws; draws with known principal (7-hit) winner count; draws with principal winners >0; sum of principal winners; average winners among draws with >0; and average known principal prize amount per known rate row (not per winner). Also show principal-winner draw share of all principal-winner draws, denominator all weekdays' draws with known winner count >0. Parse prize amount in integer centavos where representable, otherwise unavailable; arithmetic for monetary totals uses checked integers. Rate averages use only rows with that field present, regardless of winner count, and display their own denominator. Other available 6-, 5-, 4-hit and lucky-month prize tiers get analogous winner and rate tables, each with independent known-field counts and missing warnings. No conditional chance of winning is inferred. Example: Monday winner counts [2,0,missing], Tuesday [1]; principal-winner shares are 1/2 each, Monday average among winning draws is 2, Tuesday is 1, and Monday's known count is 2 of 3. If amounts on these winning draws are 100 and 200 centavos, their respective averages are 100 and 200; missing values do not enter an amount average. Show unknown if denominator is zero.
- **S22 month and prize series:** month series includes all 12 month categories; principal-prize series event is known 7-hit winner count >0, non-event is known count 0, unknown is missing/invalid. Per series show occurrence count, closed waits between consecutive events measured as number of intervening draws (including zero), histogram of closed waits, and the current open delay separately as censored. The first event has no closed wait. A prize gap containing any unknown status is unavailable rather than measured; an unknown after the last known event makes current delay unavailable. No event means delay unavailable. For months [1,1,2,1], month 1 has count 3, closed waits [0,1], and current open delay 0. For winner states [yes,no,yes,unknown,no], principal winners have count 2, one closed wait 1 and current delay unavailable; unknown count 1. Separate closed waits from censored tails; percentages of waits use the number of known closed waits. These choices correct legacy omission of zero gaps and treatment of an open tail as complete.
