# Features

- BOOT-1 (historical bootstrap): the initial binary printed a development notice; this behavior was superseded by the interactive-analysis change.
- IA-01–IA-07: [interactive historical analysis](interactive-strategies.md) provides a local-workbook menu and individually selected calculations, with Linux implementation and integration evidence recorded in [PROOF](../proof/interactive-strategies.md). Candidate generation and simulations remain future scope; no winning advantage is promised.
  - 22 implemented strategies (S01–S22): parity (S01), repeat count (S02), historical recurrence (S03), adjacent sequences (S04), longest consecutive run (S05), sum (S06), digital root (S07), number dispersion (S08), gaps (S09), decade groups (S10), last-digit columns (S11), matrix maxima (S12), full coverage cycles 27/31 (S13), ordinal rank (S14), individual numbers (S15), lucky month (S16), historical frequency and absence (S17), distance (S18), mean of roots (S19), frequency-delay dispersion (S20), weekly prize analysis (S21), prize and month series (S22).
  - Each strategy result includes charts or tables, labeled sections, eligible counts, units and a series detail panel for applicable categories. Keyboard-only operation with Brazilian Portuguese labels.

- DEV-DATA-1: Development workflow refreshes the official workbook once per local working day, with force refresh and previous-copy protection. See [change scenarios](../../openspec/changes/atualizar-resultados-diarios/specs/atualizacao-resultados/spec.md). This does not implement statistical analysis.
