# Shared descriptive statistics for historical series

Status: owner-confirmed scope, implemented formulas and edge handling for this stage; verification is recorded in [PROOF](../proof/interactive-strategies.md). Applies in addition to [S01–S22](numerical-contracts.md); it does not authorize candidate generation or prediction claims. Source: Chutan `legacy/chutan/internal/stats/serie.go` and `medidasdispersao.go`; see [legacy inventory](../../docs/analise-estrategias-legado.md). The owner confirmed inclusion of all measures that can be defined and validated, with documented corrections to legacy behavior.

## Series and populations

For each individually selected strategy, expose a scrollable series detail for each category that has an ordered occurrence sequence: discrete result categories and rounded continuous result categories per draw, the two distinct S13 cycle-duration sequences (unit: completed cycle), each S15 number, each S16/S22 month, and the S22 principal-prize event. For multidimensional strategies use separately labeled metric/category series; do not mix distinct metrics, cycle thresholds or prize tiers. For prize metrics with optional fields, use only actual known observations and preserve unknown positions, not zeroes. When a strategy's leading positions are undefined because no prior history or coverage exists, exclude them from that series population rather than counting them as unknown events, and state how many positions were excluded so the series population can be reconciled with the result notice's valid/unavailable counts; when a result has no meaningful category sequence, explain that the series detail is unavailable instead of fabricating one.

A known event at one-based observation position p and event number j records cumulative periodicity floor(p/j). This is a historical description, not a probability or a forecast. If an unknown position occurs before an event, its true j is unknown: exclude that event and later events from this periodicity vector and show the exclusion count; do not silently rebase. A closed wait is the number of known non-events between consecutive known events. Include 0 for consecutive events; if any status between two events is unknown, that wait is unavailable. Do not count the time before the first observed event as a closed wait. The delay from the last event to the current end is shown separately as right-censored and excluded from closed-wait statistics; if an unknown appears after the last event, the current delay is unavailable. A series without events has unavailable open delay. Display raw category, observation unit, sample range, eligible count, unknown/exclusion count, periodicity sample count and closed-wait sample count.

For each category, calculate the following measures **separately for the cumulative periodicity vector and the closed-wait vector**, with the number of included observations. A nonempty vector of finite, nonnegative observations is required. Empty vectors: every statistic unavailable. Output the exact integer observations in a scrollable table and the real-valued measures to two decimal places under [shared numeric rules](numerical-contracts.md#shared-conventions). Chart distributions when suitable, with numeric tables.

## Measures and edge cases

Let n be vector length, x_i each value, and mu=sum(x_i)/n. Compute in `f64` without rounding intermediate values. Min, max, range, arithmetic mean, mean of square roots, RMS and MAD follow the shared numerical definitions. Mode returns **all** values tied for highest count, in increasing order. Empirical median is the sorted value at one-based index ceil(n/2), matching Chutan's empirical quantile, including for even n; it is not the average of the two central values.

- Geometric mean is exp(sum(ln(x_i))/n) for all positive values; if at least one value is zero and none negative, it is 0. Harmonic mean is n/sum(1/x_i) for all positive values and unavailable when any value is zero.
- Circular mean interprets values as angles in **radians**, as in the legacy `CircularMean`: `atan2(sum(sin(x_i)), sum(cos(x_i)))` normalized to [0, 2π). Explicitly label it a mathematical angle transformation; raw draw counts and waits are not intrinsically angular and this does not establish a lottery pattern. If resultant length is at most `1e-12 * n`, report unavailable because direction is numerically indeterminate.
- Population variance `m2=sum((x_i-mu)^2)/n`; population SD `sqrt(m2)`. Additionally reproduce legacy Gonum sample variance `sum((x_i-mu)^2)/(n-1)` and sample SD as its square root; they are unavailable for n<2. Label population and sample measures distinctly. Coefficient of variation is `100*sqrt(m2)/mu` percent; unavailable if mu=0.
- Let `m3=sum((x_i-mu)^3)/n` and `m4=sum((x_i-mu)^4)/n`. Population moment skewness is `m3/(m2^(3/2))` and excess kurtosis is `m4/(m2*m2)-3`. Both are unavailable if m2=0. These are explicitly defined population moments and are not a claim of unbiased sample estimates; disclose the difference from any Gonum estimator where applicable.
- Reject negative, non-finite or otherwise invalid observations for these series and report the reason instead of applying logarithms or square roots, and never substitute zero. The implementation rejects the affected measurement with the reason (`InvalidObservation`) rather than returning a partially usable sample, and the terminal presents it as an unavailable series. Monetary totals in the prize series use checked integer addition, so an overflow is reported instead of wrapping.

## Reference cases

For `[1,2,3]`: min=1, max=3, range=2, all three values are modes, arithmetic mean=2, geometric mean≈1.81712, harmonic mean≈1.63636, circular mean=2 radians, empirical median=2, mean of roots≈1.38209, RMS≈2.16025, MAD=2/3, population variance=2/3, population SD≈0.81650, sample variance=1, sample SD=1, CV≈40.82483%, skewness=0 and excess kurtosis=-1.5. The displayed two-decimal values follow the shared binning rule. For `[1,2,3,4]`, empirical median=2; for `[0,0]`, geometric mean=0 and harmonic mean, CV, skewness and excess kurtosis are unavailable. For one value, sample variance and sample SD are unavailable. For category states `[yes, yes, no, yes]`, events are at positions [1,2,4], cumulative periodicities [1,1,1], closed waits [0,1], and open delay 0 (censored). For `[yes, unknown, yes]`, the second event's periodicity and intervening wait are unavailable, not 1 or 0.

## Corrections from legacy

Chutan excludes zero waits and adds an open tail to its wait vector; this contract retains zero and separates the censored tail. It uses contest identifiers as observation positions; this contract uses validated snapshot positions. It leaves some zero/empty cases and map-copy behavior unclear; this contract makes unavailable results explicit and requires actual numerical tests. Circular means keep the legacy radians interpretation but are labeled to avoid implying a physical periodic interpretation. Distinguish an unavailable metric from a valid zero; include missing observations in the visible context.
