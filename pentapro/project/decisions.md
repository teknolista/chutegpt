# Decisions

- DEC-1: Rust CLI targeting Linux desktop for this stage (owner decision). The earlier Windows/Linux/macOS target is superseded; Windows and macOS may be revisited in a future stage.
- DEC-2: PentaPRO maintained specification and OpenSpec change workflow (user, 2026-11-16); see [change control](../process/change-control.md).
- DEC-3: Cargo edition 2024 with pinned direct dependencies for the interactive-analysis increment (implementation choice, 2026-11-16): Ratatui 0.30.2 with Crossterm backend 0.29.0, Calamine 0.38.0 (dates), Chrono 0.4.42, serde_json 1.0.145, sha2 0.10.9, zip 9.0.0 (deflate). Ratatui uses the `unstable-rendered-line-info` feature for wrapped-line measurement; this feature is unstable and must be revalidated on any Ratatui update. Minimum supported Rust version and exact supported Linux versions are Pending.
- DEC-4: Project prompts and assistant responses use Brazilian Portuguese; `docs/` and the root README use Brazilian Portuguese; PentaPRO and OpenSpec specification artifacts use English (user, 2026-11-16).
- DEC-5: Preserve all root README content and sections; progressively add, adjust and update relevant content when project and usage information becomes known, identifying unresolved details. Removal requires explicit user authorization; at final delivery, ask the user before removing any unfilled section (user, 2026-11-16).
- DEC-6: The full library suite is run with `cargo test -- --test-threads=1` so results are deterministic. Observed 2026-11-17: with the default parallel harness, `ui::tests::preflight_updates_menu_status_without_starting_analysis` failed intermittently because its bounded polling budget (500 × 10 ms) expired while several tests were concurrently reading the same official workbook. No timeout exists in `data::load`; the recorded limitation is the test's fixed wait budget under file-read contention, not a defect in the loader or in the analysis modules. The 2026-11-17 snapshot passed 39/39 single-threaded. The later synthetic-fixture change removed most shared-workbook reads; the historical parallel flake has not been re-characterized. Keep the sequential command as the required gate; current results are in PROOF.
- DEC-7: PRODUCT requirements and acceptance criteria are independent of implementation language and framework; record selected languages, libraries and architecture in PROJECT. This separation is required so the PentaPRO contracts can guide a different implementation without changing user-visible behavior (owner, 2026-11-17).
- DEC-8: Prompt logging (owner, 2026-11-17): every prompt handled in the repository is appended to the local, git-ignored `AGENTS.log` before any other action. The mandatory rule lives in the root `AGENTS.md` because that is the file the harnesses load; the detailed policy is in `docs/agents-log-policy.md`, with thin pointers in `CLAUDE.md`, `.github/copilot-instructions.md`, `.cursor/rules/` and `.windsurfrules`. Capture is mechanical where the harness allows it: the OpenCode 2.0.31 user-level plugin `~/.config/opencode/plugins/agents-log.ts` appends real user prompts from the session `context` hook before dispatch for every project on this machine, discards harness-injected user-role context (the plan-mode reminder and the conversation checkpoint, which differ from real prompts in their `metadata`), deduplicates message ids in memory only (no state file, so a resumed session may repeat earlier prompts), redacts known credential patterns as best effort and aborts the request when the append fails. The project-local copy was removed to avoid a second append; `.opencode/plugins/` is empty. Other harnesses depend on instruction obedience and manual appending, and must not duplicate an entry the plugin already wrote. `~/.config/git/ignore` (configured through `core.excludesFile`) ignores `AGENTS.log` and `AGENTS.log.*` in every repository; `.opencode/`, `.cursor/` and `.windsurfrules` remain git-ignored development artifacts, so those pointers are local tooling.
- DEC-9: Workbook robustness remediation (2026-11-17 peer review): the loader enforces the 15 MiB compressed read, the 50 MiB declared uncompressed total and, additionally, the bytes actually inflated per entry; text cells above 64 KiB are rejected before dense materialization. Draw invariants (seven strictly increasing numbers in 1..31 and month 1..12) are checked in the loader and rechecked by the analysis entry points, so a public `Draw` cannot silently corrupt cycle bits or index out of bounds. ISO date strings with and without a time component are accepted alongside `DD/MM/YYYY` text and Excel dates. The pool/declared distinction and the shared hundredths rounding rule (`src/numeric.rs`) are recorded in the module map; duplicate interval-censoring code in `series.rs` and `historical.rs` remains a known maintenance risk to consolidate in a future increment.
- Interactive historical-analysis scope and contracts: confirmed for the active [change](../process/interactive-strategies.md); other feature scope and release decisions remain Pending.
