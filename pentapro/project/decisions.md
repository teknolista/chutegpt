# Decisions

- DEC-1: Rust CLI targeting Linux desktop for this stage (owner decision). The earlier Windows/Linux/macOS target is superseded; Windows and macOS may be revisited in a future stage.
- DEC-2: PentaPRO maintained specification and OpenSpec change workflow (user, 2026-11-16); see [change control](../process/change-control.md).
- DEC-3: Cargo edition 2024 with pinned direct dependencies for the interactive-analysis increment (implementation choice, 2026-11-16): Ratatui 0.30.2 with Crossterm backend 0.29.0, Calamine 0.38.0 (dates), Chrono 0.4.42, serde_json 1.0.145, sha2 0.10.9, zip 9.0.0 (deflate). Ratatui uses the `unstable-rendered-line-info` feature for wrapped-line measurement; this feature is unstable and must be revalidated on any Ratatui update. Minimum supported Rust version and exact supported Linux versions are Pending.
- DEC-4: Project prompts and assistant responses use Brazilian Portuguese; `docs/` and the root README use Brazilian Portuguese; PentaPRO and OpenSpec specification artifacts use English (user, 2026-11-16).
- DEC-5: Preserve all root README content and sections; progressively add, adjust and update relevant content when project and usage information becomes known, identifying unresolved details. Removal requires explicit user authorization; at final delivery, ask the user before removing any unfilled section (user, 2026-11-16).
- DEC-6: Test suite (`cargo test`) must be run with `--test-threads=1` or individually for deterministic results when running all 36 library tests together; running in parallel causes intermittent failure of `ui::tests::preflight_updates_menu_status_without_starting_analysis` due to file-access contention on the official workbook (observed 2026-11-17). The test logic is correct; the race is inherent to the parallel-I/O pattern and the shared workbook file. Single-threaded execution is confirmed stable (36/36). This is not a code defect in the analysis modules; it is a test-harness constraint.
- Interactive historical-analysis scope and contracts: confirmed for the active [change](../process/interactive-strategies.md); other feature scope and release decisions remain Pending.
